## 3. Subagent 子系统架构

```
run_agent.py
  ├── SubagentRegistry      → 角色注册（内置 + 自定义）
  ├── SubagentTaskManager   → 线程池 + 队列 + 持久化
  ├── SubagentRunner        → 创建隔离 AgentSession
  ├── AgentTool             → LLM: 启动子代理
  ├── AgentTaskTool         → LLM: inspect/wait/cancel
  └── AgentSession (父) ──→ AgentSession (子)
       └─ ToolExecutor        └─ 隔离的 ToolExecutor + SubagentExecutionPolicy
```

### 任务状态机

`queued → running/waiting_tool/cancelling → completed/failed/cancelled/orphaned`

进程重启时运行中任务标记为 `orphaned`，不会重放。

### 权限模型

三层校验：角色层（工具白名单 + bash_mode）→ 策略层（路径校验 + 工作区边界）→ 执行器层（ALWAYS_DENIED_TOOLS + .git/.env 拒绝）

## 4. 主流程集成

- **初始化**：`SubagentRegistry(WORKSPACE_ROOT)` + `SubagentTaskManager(...)`，最大 4 个后台 worker、32 个排队上限
- **工具注册**：`_register_subagent_tools()` 注册 `AgentTool` 和 `AgentTaskTool`
- **会话注入**：`subagent_task_registry` 注入 `AgentSession`
- **进度通知**：每轮模型调用前 `drain_parent_updates()` 生成 `<subagent-update>` 标签
- **清理**：`shutdown(timeout=2.0)` 取消所有任务，超时标记 orphaned
